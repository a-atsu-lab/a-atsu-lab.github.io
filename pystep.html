ダウンロードとして保存

このブラウザ（または学校の設定）では、保存先を選ぶ画面が使えません。ファイルを「ダウンロード」フォルダに保存します。


ブラウザの設定で「ダウンロード前に各ファイルの保存場所を確認する」をオンにすると、保存する場所を毎回選べます。

PyStep の使い方

左の「部品」をクリックすると、カーソルの位置にプログラムの部品が入ります。エディタへドラッグすると好きな行に置けます。灰色の▢の部分を書きかえましょう（Tab で次の▢へ）。

手で打つときは、文字を入力すると候補が出ます。↑↓ で選んで Enter か Tab で決定、Esc で閉じます。

課題モードと自由制作モード

上の「課題モード」では、課題バーで学年・組・番号・名前を選び、問題の番号を押すとその問題のファイル（例：hissu1.py）が開きます。問題文は左の欄に出ます（「部品」に切り替えもできます）。プログラムを書いたら、実行結果の欄の「判定する」（F9）を押すと、入力や乱数を変えながら何回か実行して正しいかを確かめます。書き方は人それぞれで構いません。＋α も一緒に判定します（考える問題は判定しません）。「達成状況を画像で保存」で、正解した問題の一覧を PNG 画像で保存できます。

セーブデータ：課題バーの「セーブ（json）」で、生徒情報・達成状況・課題のプログラムを1つのファイル（PyStep_学年-組-番号_名前_日時_save.json）に保存します。セーブするたびに、その日時の名前で新しいファイルができます（前の記録も残ります）。読み込むときは、いちばん新しい日時のものを選んでください。情報処理室のパソコンは再起動すると記録が消えるので、授業の最後に個人フォルダへセーブし、次の授業で「読み込む（json）」から続きを始めてください。セーブしていない変更があると、セーブボタンに赤い印が付きます。

保存の形式は2つあります。セーブ（json）は進み具合と課題のプログラムをまとめて保存するもの、メニューの上書き保存（py）・名前をつけて保存（py）は今開いているプログラム1つを Python のファイルとして保存するものです。ファイルを開く・保存する、サンプル、文字の大きさ、表示の明るさは「メニュー」にあります。

「自由制作モード」は、課題とは別のファイルで自由にプログラムを作る場所です。2つのモードのファイルは別々に保存されます。

色の意味

if / elif / else（条件）、for / while（くり返し）、def / class（関数）、try / with、import。字下げされた「まとまり」の左に同じ色の線が引かれます。行番号の横の ▾ でまとまりを折りたためます。全角の記号やスペースは赤い波線で知らせます。

このアプリについて

  • Python 本体（Pyodide）をブラウザの中で動かしています。最初の起動にはインターネット接続が必要です。
  • import できるのは標準ライブラリ（random, math, time, datetime, statistics など）と numpy・matplotlib・pandas などです。turtle や tkinter など画面を開くものは使えません。
  • 「共通テスト表記」を押すと、書いているプログラムを大学入学共通テストの「共通テスト用プログラム表記」で表示します。「コピー」で文字として取り出せます。
  • 右の「フローチャート」には、書いているプログラムの流れ図が自動で描かれます。記号をクリックするとその行へ移動し、「1行ずつ」実行では今の位置が光ります。「隠して予想する」で答え合わせにも使えます。
  • タブで複数のファイルを作ると、import ファイル名 で自作モジュールとして読み込めます。
  • 書いたプログラムはこのブラウザに自動で一時保存されます。大事なものは「保存」で .py ファイルにしてください。
  • Chrome / Edge では input() の入力欄が実行結果の中に出ます。ほかのブラウザでは入力用の小さな画面が開き、「1行ずつ」は使えません。
